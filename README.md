# TOOKU

Buat aplikasi BARAKA (Barang Apik Koperasi Akademik), marketplace barang sekolah bekas layak pakai yang dikelola koperasi sekolah. Rancang pengalaman pembeli seperti aplikasi online shop populer: home mobile-first dengan search bar, banner promo/impact, kategori horizontal (Seragam, Buku, Atribut, Alat Tulis), grid produk dua kolom, flash/unggulan, badge Lolos Kurasi Koperasi, harga dan kondisi. Sertakan navigasi bawah Beranda, Pesanan Saya, Profil. Buat detail produk dengan galeri besar, harga, kondisi plus-minus transparan, badge verifikasi, informasi pengambilan di koperasi, tombol sticky 'Pesan Sekarang'. Buat keranjang/booking flow yang menghasilkan kode pengambilan dan batas waktu 1x24 jam. Tambahkan halaman pesanan dengan status dan countdown visual. Buat mode Admin Koperasi yang mudah diakses untuk dashboard statistik, daftar pesanan dan validasi/selesaikan pesanan, manajemen produk, serta form tambah produk termasuk upload foto, kategori, harga, stok, kondisi/minus. Gunakan data contoh realistis. Tema clean modern: navy dominan, putih bersih, aksen kuning emas/oranye; rounded card, responsif dengan tampilan admin nyaman di tablet/desktop. Jadikan prototype berfungsi dengan interaksi navigasi dan booking yang jelas.
